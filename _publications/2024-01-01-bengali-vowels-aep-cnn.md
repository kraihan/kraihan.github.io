This work explores **auditory evoked potentials (AEP)** as a modality for recognizing **Bengali vowels** from EEG recordings. Using the first EEG AEP dataset for imagined Bengali language tasks — collected with a low-cost OpenBCI acquisition system — a convolutional neural network is trained to classify vowel stimuli.

The proposed model demonstrates that robust vowel recognition is feasible from non-invasive EEG, contributing to language-specific brain–computer interface systems. **The paper received the IEEE Best Paper Award.**
